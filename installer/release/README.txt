PesoWise for Tally — customer install

1. Double-click PesoWise-for-Tally-Setup.exe
2. Browser opens — paste pairing code from PesoWise (Admin → Tally integration)
3. In Tally once: F12 load TDL from C:\pesowise, F1 enable port 9000
4. In PesoWise: Reports → Sync to Tally

Full app folder: installer/release/app/
