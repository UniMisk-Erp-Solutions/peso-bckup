## End-to-end path (production code)

1. **Admin UI** → `start-tally-sync` Edge → `create_tally_sync_job_v1` → `run-tally-sync-job` prepares rows into `tally_sync_job_items`.
2. **`run-tally-sync-delivery`** → `mapPreparedJobItems()` → `tally_sync_delivery_batches` (`xml_payload`, `delivery_updates`, `status=pending`).
3. Job → **`waiting_for_connector`**.
4. **Agent `run`** → `tally-connector` Edge → `connector_claim_delivery_batch_v1` (device token → `connector_id` → **`organization_id`**).
5. Agent replaces `SVCURRENTCOMPANY` placeholder → **`POST` Import Data** envelope to `127.0.0.1:9000` (delivery only).
6. **`parseTallyImportResponse`** → **`connector_ack_delivery_batch_v1`** (`p_success` from parser).

Doctor **does not** participate in this path (no Tally HTTP in doctor after 0.2.1-agent).

## GO / NO-GO

### **NO-GO** for immediate one-shot live metadata E2E

**Blockers (must fix or explicitly accept before Agent run):**

1. **Delivery HTTP timeout 120s** — exceeds required **≤15s**; increases hang/crash risk on TallyPrime 7.1.
2. **Automatic batch retry** — lease expiry + failed ack returns batch to **`pending`**; agent loop retries claim/delivery (not “single attempt only”).
3. **Human gate:** **`queue_safe`** (global/smoke/MicroLink pending = 0) must be re-verified on backup DB **immediately before** Sync — not done in this offline pass.
4. **Scope:** First batch includes **employee + project masters**, not metadata ledger alone (no vouchers, but more than PW-META-HTTP-001 single-message test).

**Ready (no block):**

- Metadata **LEDGER Create** append-only architecture, UDF, group parent, no vouchers for daily project.
- Org-scoped claim via device token.
- Skipped quarantine batches not claimable.
- ACK gated on **`parseTallyImportResponse` ok** (CREATED/ALTERED/DELETED, no LINEERROR/EXCEPTIONS).
- Safe doctor passed; live Tally XML probes stopped.

### If NO-GO items addressed — human steps (do not run until then)

1. Re-run **`ssh-verify-queue-safe.mjs`** → `queue_safe: true`.
2. Confirm Tally stable; **do not** re-enable doctor company XML.
3. One **Daily Project Report** sync (smoke admin) — creates **one new job**.
4. Cap delivery timeout / single-attempt policy in agent (code change + rebuild).
5. **`PesoWise-Tally-Agent.exe run`** once; watch **first batch only**; stop agent after first ACK.
6. Manual verify new **`PW-META-…`** ledger under **PesoWise Metadata** in Tally.
